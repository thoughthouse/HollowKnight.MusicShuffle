# MusicShuffle

Hollow Knight mod that randomizes the soundtrack.

### Modes
**Off** - Music will not be shuffled. Essentially disables the mod.

**Fixed** - Shuffles the tracks around once at the beginning of the game, or when the "Re-shuffle" button is pressed.

**Chaos** - Any time the track would change, a random track is played

### Boss Themes
**Mixed** - Boss themes are mixed in with the other tracks

**Separate** - Boss themes only play in situations where a boss theme would normally play

### Include Shade
Some of the music is hard to hear with the shade's effect, so there's an option to leave it un-randomized.

### Include Colosseum
There's six different colosseum drum beats of varying intensity. If that's too many drum beats for you, you can leave them un-randomized.
